# Security policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Please **don't** open a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/Shotgn16/LifeHub/security/advisories/new)
instead, and include steps to reproduce the problem. You'll get a reply as soon as possible.

For how LifeHub stores data and handles authentication, see [docs/security.md](docs/security.md).
