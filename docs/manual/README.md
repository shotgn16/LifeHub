# LifeHub manual

Welcome! These guides take you from download to a working LifeHub, one step at a time. You don't
need to be technical — every step says exactly what to click.

## 1. Pick how you'll use LifeHub

| I want… | Choose | Guide |
|---|---|---|
| LifeHub just on my phone, nothing else | **Use LifeHub on this phone** (in the app) | [Phone apps](phone-apps.md) |
| LifeHub on my computer, just for me | **This computer only** | your computer's guide below |
| LifeHub on my computer **and** in the app on my phone | **This computer + my phone** | your computer's guide, then [Phone apps](phone-apps.md) |
| One LifeHub for the whole household, on a computer that stays on | **A server for my household** | your computer's guide, then [Household](household.md) |
| LifeHub in Docker | **Docker** | [Docker](docker.md) |
| LifeHub inside Home Assistant | **Home Assistant** | [Home Assistant](home-assistant.md) |

You don't have to decide now: the LifeHub app asks when you first open it, and you can change your
mind later in **Settings → This computer**.

## 2. Install it

| Your computer | Guide | Download |
|---|---|---|
| Windows 10 or 11 | [Windows](windows.md) | `LifeHub-…-Windows-x64-Setup.exe` |
| Mac (Apple chip or Intel) | [Mac](mac.md) | `LifeHub-…-macOS-AppleSilicon.dmg` or `…-Intel.dmg` |
| Linux (Ubuntu, Debian, Mint, Fedora, Arch, Raspberry Pi OS…) | [Linux](linux.md) | `LifeHub-…-Linux-amd64.deb` / `.tar.gz` (or `arm64`) |
| Android phone or tablet | [Phone apps](phone-apps.md) | `LifeHub-…-Android.apk` |
| iPhone or iPad | [Phone apps](phone-apps.md) | `LifeHub-…-iPhone-iPad-unsigned.ipa` |

All downloads are on the **[Releases page](https://github.com/shotgn16/LifeHub/releases/latest)**.
Each installer contains everything LifeHub needs, so there's nothing else to install first.
